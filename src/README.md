## 🌟 What is Arthya?

Arthya (derived from Sanskrit, meaning "wealth" or "prosperity") empowers you to take control of your financial future with intuitive tools for tracking income, managing expenses, monitoring assets, and achieving your financial goals. Whether you're a freelancer juggling multiple clients, an entrepreneur with diverse revenue streams, or someone managing complex personal finances, Arthya provides the clarity and insights you need.

**Key Benefits:**
- 🎯 **Complete Financial Visibility** - See your entire financial picture in one unified dashboard
- 🔐 **Privacy-First Design** - Your sensitive financial data never leaves your device
- 🌍 **Multi-Currency Support** - Perfect for international businesses and global income sources
- 📊 **Smart Insights** - Get actionable recommendations based on your financial patterns
- 🎨 **Beautiful Interface** - Enjoy a clean, modern design with golden gradient theme and dark/light modes

## ✨ Features

- 📊 **Unified Dashboard** - Overview of all your financial data at a glance
- 💵 **Multi-Source Income Tracking** - Track income from various sources
- 💳 **Multi-Account Management** - Manage multiple bank accounts and wallets
- 🏠 **Asset & Investment Tracking** - Monitor your assets and investments
- 📉 **Expense Management** - Categorized expense tracking with analytics
- 🎯 **Goal Planning** - Set and track financial goals with purchase simulators
- 📈 **Forecasting Tools** - Project future financial scenarios
- 🌍 **Multi-Currency Support** - Support for multiple currencies
- 🎨 **Dark/Light Mode** - Beautiful interface with theme support
- 🔒 **Privacy-First** - All data stored locally in your browser

## 🚀 Tech Stack

- **React 18** with TypeScript

- **Tailwind CSS v4** for styling
- **Recharts** for data visualization
- **Shadcn/ui** component library
- **Local Storage** for data persistence

## 🏃‍♂️ Getting Started

### Prerequisites

- Node.js 18 or higher
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   cd arthya
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`

## 📦 Building for Production

```bash
npm run build
```

The optimized production build will be in the `dist` folder.

## 🎯 Usage

1. **First Time Setup**: Follow the guided tour to set up your first account
2. **Add Income Sources**: Track all your income streams
3. **Add Expenses**: Categorize and monitor your spending
4. **Manage Assets**: Keep track of your investments and assets

## 🔒 Privacy & Security

- **No Backend Required**: All data is stored locally in your browser
- **No Account Required**: Start using immediately without sign-up
- **Your Data Stays Yours**: No data is sent to any server
- **Dummy Data Mode**: Practice with simulated data before adding real information
